## 구축한 자동화 파이프라인

```
코드 작성 (Claude Code)
    ↓

    ↓
pre-push: 유닛 테스트 자동 실행
    ↓
PR 생성 (GitHub MCP)
    ↓
자동 코드 리뷰 (GitHub Actions + Claude API) ← 10일차
자동 커버리지 리포트 (JaCoCo) ← 12일차
    ↓
이슈 자동 분석 및 등록 (GitHub MCP) ← 13일차
    ↓
이슈 → 수정 → PR 자동화 (GitHub MCP) ← 14일차
    ↓
릴리즈 노트 자동 생성 (GitHub MCP + gh CLI) ← 15일차
```
