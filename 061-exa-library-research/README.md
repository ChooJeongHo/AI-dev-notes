## 핵심 발견 — 의존성 충돌 연결 고리

**Coil 3.5.0 업그레이드가 막힌 이유:**

```
Coil 3.5.0 → Kotlin 2.4.0 필요
    ↓
Hilt 2.59.2 → kotlin-metadata-jvm이 Kotlin 2.3.x까지만 지원
    ↓
Coil 3.5.0 즉시 업그레이드 불가
    ↓
Hilt가 Kotlin 2.4.0 지원 버전 출시 대기
```

이 연결 고리는 각 라이브러리를 개별로 보면 발견하기 어렵다. Exa로 병렬 검색하면서 전체 그림이 보였다.

---

## 라이브러리별 상세

### Paging 3: 3.4.1 → 3.5.0 ✅ 즉시 업그레이드

- KMP(Kotlin Multiplatform) 타겟 추가
- 호환성 문제 없음
- `libs.versions.toml`에서 버전만 변경하면 됨

### Hilt: 2.59.2 — 최신

- 현재 최신 버전
- Kotlin 2.4.0 지원 버전 출시 시 Coil도 같이 업그레이드 가능

### Coil: 3.4.0 → 3.5.0 ⚠️ Hilt 업그레이드 후

- Kotlin 2.4.0 필수 → Hilt 호환 버전 나올 때까지 대기
- 기능 개선 포함이지만 호환성 문제로 즉시 적용 불가

### Room: 2.x 계열 유지 권장

- Room 2.8.4가 2.x 최신 stable
- Room 3.0은 완전히 새로운 artifact (`androidx.room3`)
  - KAPT 폐지 → KSP 전환
  - SQLiteDriver 전면 교체
  - 대규모 Breaking Change → 장기 마이그레이션 계획 필요
