# 043 - Claude Code로 앱 스토어 설명문 자동 생성

**프로젝트 코드를 직접 분석해서 Google Play 스토어 등록용 설명문 자동 생성 — MovieFinder·MediScan 2개 앱 적용**

---

## 목적

앱 출시 시 가장 귀찮은 작업 중 하나인 스토어 설명문 작성을 자동화.  
README나 문서가 아닌 **실제 코드(strings.xml, 소스 파일)를 직접 분석**해서 정확한 기능 설명 생성.

---

## 사용 프롬프트

```
프로젝트 분석해서 구글 플레이스토어 앱 설명문 자동 생성해줘.

포함 내용:
- 짧은 설명 (80자 이내)
- 긴 설명 (4000자 이내)
- 주요 기능 목록
- 키워드 (검색 최적화용)
```

---

| 항목 | MovieFinder | MediScan |
|------|------------|---------|
| 짧은 설명 | 40자 | 46자 |

| 특이사항 | TMDB 연동·AI 태그 자동 발굴 | 면책조항 자동 포함 |

## MovieFinder 짧은 설명

```
영화 검색·즐겨찾기·시청 통계를 한 앱에 — TMDB 기반 나만의 영화 기록장
```

```
약봉투·처방전을 찍으면 약품 정보 즉시 확인. 복약 알림·외형 검색·AI 상호작용 분석 제공.
```

## 핵심 발견

### strings.xml에서 숨겨진 기능 자동 발굴

Claude Code가 CLAUDE.md가 아닌 `strings.xml`을 직접 읽어서 문서에 없던 기능들을 발굴했다.

**MovieFinder에서 새로 발굴된 기능:**
- TMDB 계정 연동 (즐겨찾기·워치리스트 동기화)
- AI 추천 태그
- 컬렉션(시리즈) 뷰
- 통계 카드 소셜 공유
- 데이터 백업·복원

→ CLAUDE.md에 없던 기능들이 스토어 설명의 차별화 포인트가 됐다.

### Play Store 최적화 인사이트 자동 적용

Claude Code가 스토어 알고리즘까지 고려해서 작성했다:

| 인사이트 | 적용 방식 |
|---------|---------|
| 첫 250자가 "더보기" 없이 노출 | 가장 중요한 기능을 서두에 배치 |
| 키워드 별도 입력란 없음 | 본문에 자연스럽게 녹임 |
| 면책조항 필수 (의료 앱) | MediScan에 자동 포함 |

## 느낀 점

스토어 설명문은 "앱을 다 만들고 나서 귀찮게 써야 하는 것"으로 생각했는데, Claude Code가 코드를 읽고 자동으로 만들어줬다.

특히 CLAUDE.md에도 없던 기능들을 `strings.xml`에서 직접 발굴한 게 인상적이었다. 개발자 본인도 모르게 넣어둔 기능이 스토어 설명에 포함될 수 있다.

**앱 출시 준비 시간을 크게 단축할 수 있다. 코드만 있으면 스토어 등록 준비 완료.**
