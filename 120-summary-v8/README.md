# 120 - 8차 실험 총정리 및 포트폴리오 v8 작성

**106~119일차 14개 실험 종합 정리 — 최초 가설을 실기기로 끝까지 따라가고, 되돌릴 조건을 미리 정하고, 확인 못 한 것은 확인 못 했다고 적은 단계**

---

## 목적

106~119일차 실험을 돌아보며 8차 포트폴리오를 작성한다.
7차("같은 증상, 다른 원인")에서 8차는 **"결론은 뒤집힌다"**로 발전했다.

## 8차에서 배운 핵심 교훈

**"최초 가설은 빙산의 일각일 수 있다"**
109(3중 결함), 116(60개의 정체), 117(진단 두 번 뒤집힘).

**"되돌림도 성과이고, 되돌릴 조건은 미리 정한다"**
112는 결과로서의 되돌림, 115는 사전 합의된 롤백 조건.

**"수치는 무엇을 쟀는지 구분해야 한다"**
68초와 48초는 다른 것을 쟀고, "동작이 고쳐졌다"와 "빨라졌다"는 다른 주장이다.

**"같은 기능이라도 구현 계층이 다르면 위험도 다르다"**
113(XML View의 세 겹 함정) vs 114(Compose에서는 구조적으로 성립 안 함).

**"AI의 보고와 전제는 증거와 대조한다"**
106(서브에이전트 보고를 HTML 리포트로 재확인), 113(프롬프트의 과거 언급이 기록과 불일치).

**"확인하지 못한 것은 확인하지 못했다고 적는다"**
API 24~32 경로, 첫 결과 시점, KMRB 필터 켠 상태의 호출 감소는 추정이라고 명시.
