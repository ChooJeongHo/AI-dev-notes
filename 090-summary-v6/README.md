## 6차에서 배운 핵심 교훈

**"AI가 모른다고 답할 때, 문제는 대개 데이터의 부재다"**
076~078일차에서 실증 — 임베딩을 바꿔도 안 풀리던 질문이 코퍼스 확장으로 풀렸다.

**"재사용은 스캐폴딩과 도메인 지식을 나눠서 평가해야 한다"**
083/085/087일차 세 번 모두 같은 결론 — 구조는 재사용되지만 판정 근거는 매번 새로 설계해야 한다.

**"정적 사실만 확인하면 시점을 놓친다"**
083일차와 088일차에서 같은 구조의 함정이 형태를 바꿔 재발견됐다.

**"실기기가 아니면 안 보이는 문제가 있다"**
056/079/081일차까지 세 번째로 확인 — 정적분석을 전부 통과해도 실기기에서만 드러나는 문제가 있다.

**"AI가 검증한 AI도 다시 검증해야 한다"**
080일차에서 과거의 "정정"조차 근거가 부정확했음을 발견했다.
