## 목적

CLAUDE.md가 커질수록 AI 성능에 영향을 준다는 가설 검증.  
경량화 전후 동일한 코드리뷰 요청으로 품질 변화를 수치로 측정.

---

## 실험 내용

```
1. 현재 CLAUDE.md 분석 → 불필요/중복 내용 식별

```

## 핵심 발견

**불필요한 정보를 줄이면 AI가 핵심에 더 집중한다.**

Before 리뷰에서 잡은 이슈 대부분이 After에서도 동일하게 탐지됐고,  
추가로 `stateIn` 정책 의미 차이, `IllegalArgumentException` 흡수 등 **더 심층적인 이슈가 새로 발견**됐다.

Before에서 블로킹으로 분류된 4개 이슈(Mutex 안전성, scrollToPosition UX 회귀, RemoteMediator 오프라인 가드, 검색 정규화 불일치)가 After에서는 블로킹 0개로 재분류됐다 — 컨텍스트가 줄어 노이즈가 제거된 결과로 보인다.
