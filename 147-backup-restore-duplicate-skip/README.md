## 오늘 배운 것

- **정의를 먼저 정하고 경계를 시험으로 고정했다.** "같은 시청 기록"을 (`movieId`, `watchedAt`, `title`)로 정한 뒤 S5로 제목만 다른 경우를 별도 기록으로 고정했다. 다만 S5는 수정 전에도 통과해 B에서 C로의 변경을 잡지 못한다.
- **한 곳의 수정이 앞선 수정의 부작용을 되돌렸다.** 146일차 F1 수정으로 생긴 "같은 백업 2회 후 장르 행 12"가 이번 수정으로 6이 됐다(이 시나리오 범위에서). S2는 146일차 한계 6(기존 기록 위 가져오기)을 측정으로 닫았다.
- **첫 단언에서 멈춘 실패는 뒷부분을 보여 주지 않는다.** A의 실패 4개가 모두 185행에서 멈춰 장르 값은 `RESULT` 줄로만 알았다. 148일차 변이 확인에서 "어떤 단언이 어디서 잡는지"를 볼 소재다.
- **"검출 0건"은 검사기가 값을 찾을 수 있는 입력에서 0건일 때만 의미가 있다.** 묶음은 원본에 값이 처음부터 0건이라 사본 0건만으로는 가림이 작동했다고 볼 수 없다. 같은 코드가 낱개 원본 18개에서 값을 검출한 것으로 보완했을 뿐이다.
- **설명도 실행으로 확인해야 한다.** "lint까지 다시 실행"이라는 설명이 틀렸고, 추천의 근거가 되어 있었다. 지시서의 기준 숫자(11개)도 실제 검출(10개)과 달랐다.
- **고정한 값은 놓친 일에 대해 틀린 채 남는다.** 커밋 시점으로 고정한 이탈 건수가 D3 때문에 틀렸다.
- 시간 예측 9/9는 기준을 직전 실측으로 잡은 날의 관찰이다. 이번 총 시간의 절반(51.8%)은 지시 대기였다.
