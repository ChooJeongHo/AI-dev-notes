# AI 활용 기록 009 - playwright-cli로 사람인 자동 지원 시스템 구축

> 대표님 과제: "사람인 수동 지원을 자동화해보세요" — playwright-cli를 활용한 취업 지원 자동화 기록

## 목적

Microsoft의 playwright-cli를 Claude Code CLI와 연동하여 사람인 채용 공고를 자동으로 검색하고 지원하는 시스템 구축  
매일 12시에 자동 실행되어 조건에 맞는 공고에 자동 지원

## 사용한 도구

- Claude Code CLI (터미널)
- playwright-cli (@playwright/cli) — Microsoft 2026년 초 출시
- oh-my-claudecode ralph 모드
- 대상 사이트: [사람인](https://www.saramin.co.kr)

## playwright-cli란?

2026년 초 Microsoft가 출시한 AI 코딩 에이전트 전용 CLI 도구. 기존 Playwright MCP와 달리 터미널 명령어로 브라우저를 조작한다.

| 구분 | Playwright MCP | playwright-cli |
|------|---------------|----------------|
| 방식 | JSON 기반 프로토콜 | 터미널 명령어 |
| 토큰 사용 | 많음 | 약 4배 적음 |
| AI 에이전트 연동 | 가능 | 최적화됨 |
| Claude Code 연동 | 가능 | 공식 지원 |

### 설치 방법

```bash
# playwright-cli 설치
npm install -g @playwright/cli

# Claude Code에 SKILL.md 등록
mkdir -p ~/.claude/skills/playwright-cli
curl -o ~/.claude/skills/playwright-cli/SKILL.md \
  https://raw.githubusercontent.com/microsoft/playwright-cli/main/skills/playwright-cli/SKILL.md
```

## 자동화 시스템 구성

### 검색 조건

| 항목 | 설정값 |
|------|--------|
| 검색어 | 전산, IT운영 (병행 검색) |
| 지역 | 서울 (송파구, 강남구, 광진구, 강동구, 성동구) / 경기 (성남시 수정구, 성남시 중원구, 하남시) |
| 경력 | 신입 / 경력 ~1년 |
| 고용형태 | 정규직 |
| 하루 최대 지원 수 | 6건 |

### 제외 조건

**1단계 - 제목 키워드 필터링**

> 파견, 계약

**2단계 - 공고 본문 AI 재확인**

> 제목에서 걸러지지 않은 야간/교대 관련 내용을 AI가 본문 직접 읽고 재확인 후 해당되면 스킵

### 지원 방식

- **입사지원 공고** → 사람인 저장 이력서로 자동 지원
- **홈페이지 지원 공고** → 링크만 `~/saramin/homepage_links.txt`에 수집

### 파일 구조

```
~/saramin/
├── saramin-auto.sh        # 메인 스크립트
├── saramin-auth.json      # 인증 정보
├── applied_jobs.txt       # 지원 완료 공고 ID (중복 방지)
├── homepage_links.txt     # 홈페이지 지원 링크 수집
├── log.txt                # 지원 로그 (날짜/시간/회사/공고명)
└── logs/                  # 실행별 상세 로그
```

## 한계점 및 개선 필요사항

- **직군 미스매치**: 웹프로그래머 공고가 지원됨 → 검색어 정교화 필요
- **지원 실패 2건**: 완료 확인 로직 개선 필요
- **홈페이지 지원 자동화**: 회사별 지원 폼이 달라 완전 자동화 어려움 → 링크 수집으로 대체
- **야간/교대 필터 완벽하지 않음**: 제목에 명시 안 된 경우 2단계에서도 놓칠 수 있음

## 느낀 점

playwright-cli는 MCP보다 토큰 효율이 높고 Claude Code와 연동이 자연스러웠다.  
실제로 자동 지원이 작동하는 걸 확인했지만, 검색 조건만으로 완벽한 필터링은 어렵다는 것도 알게 됐다.

AI 자동화의 핵심은 **완전 자동화보다 반복 작업을 줄이는 것**이라는 걸 느꼈다.  
사람이 확인해야 하는 부분(홈페이지 지원, 직군 적합성)은 여전히 남아있지만,  
조건에 맞는 공고를 매일 자동으로 지원해주는 것만으로도 충분히 유용하다.
