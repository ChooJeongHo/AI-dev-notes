## 5차에서 배운 핵심 교훈

**"권한 구조로 역할을 강제하는 것이 프롬프트로 부탁하는 것보다 강하다"**
`tools`에서 Write/Edit를 빼는 것만으로 "계획만 세우는" 역할을 시스템적으로 강제할 수 있었다.

**"결정론적 판단은 차단, AI의 판단은 정보 제공"**
071일차에서 세운 원칙이 073(Stop Hook), 074(사전 설계)까지 일관되게 적용됐다.

**"직관은 실측으로 검증해야 한다"**
"쪼개면 느릴 것"이라는 예상이 072일차에서 실측으로 뒤집혔다.

**"버전 숫자만으로는 위험도를 알 수 없다"**
069일차에서 버전이 그대로인데도 위험한 라이브러리(archived, deprecated)를 발견했다.

**"안전장치는 이분법이 아니라 계층이다"**
067일차(이중 피닝)와 074일차(사전 설계+결정론적 백스톱)가 같은 결론에 도달했다.
